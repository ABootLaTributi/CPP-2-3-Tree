# CPP-2-3-Tree
C++ implementation of a 2-3 tree with multi-key nodes, three-way branching, recursive search, insertion/removal operations, and depth-first tree traversals.

This implementation routes searches recursively through the left, middle, or right subtree depending on the relationship between the requested value and the node's stored keys. It also implements recursive preorder, inorder, and postorder traversals.

The interactive program lets the user insert, remove, search for, and print stored movie titles.
